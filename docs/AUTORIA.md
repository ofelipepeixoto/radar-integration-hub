# Autoria e proveniência

Projeto independente de **Carlos Felipe (`ofelipepeixoto`)**, desenvolvido com assistência de ferramentas de IA. A arquitetura de domínio, controles, adaptadores originais, testes e documentação Radar integram este trabalho. O copyright dos arquivos originais está em `LICENSE`; a licença escolhida para esses arquivos é MIT.

| Situação | Identificação adotada |
|---|---|
| Implementação nova para este projeto | Autoria Carlos Felipe / Radar; registrar escopo e validação |
| Integração por API ou SDK externo | Autoria do adaptador Radar; identificar fornecedor, versão e contrato |
| Código de terceiros copiado ou modificado com permissão | Preservar licença, copyright e avisos; registrar origem, SHA e alterações |
| Repositório independente contendo base externa | Propriedade do repositório e autoria das adaptações não substituem autoria upstream |
| Código sem licença de reutilização confirmada | Não copiar; delimitar implementação independente e proveniência |

Para cada reutilização, registrar: URL upstream, SHA/tag, caminhos incorporados, licença de cada componente, avisos, mudanças e evidência de testes. Revisar ativos, marcas, dados e condições de provedores separadamente quando fizerem parte do produto.

Criar projetos no namespace `ofelipepeixoto` é a preferência. A abertura de repositório novo depende de uma responsabilidade própria: produto, serviço ou biblioteca reutilizada por mais de um consumidor. Funcionalidades coerentes com um repositório existente entram nele, evitando duplicação. O mecanismo Fork não é obrigatório quando a reutilização e redistribuição forem permitidas.

Esta integração foi implementada no `radar-integration-hub` porque políticas, cotas e vínculo CRM já vivem aqui. Não replica o OpenClaw e não altera o histórico ou os créditos de projetos terceiros. Um eventual repositório futuro, como `radar-assistente-operacional`, só se justifica quando possuir implantação e ciclo de vida próprios.

Este registro descreve proveniência técnica e a preferência de autoria do responsável pelo projeto. Não certifica a titularidade jurídica de todos os componentes ou direitos sobre marcas.
